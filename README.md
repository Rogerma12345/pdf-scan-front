# PDF 扫描风生成器

这是一个纯前端的在线工具，可以将您的 PDF 文件转换成带有“扫描效果”的新 PDF。所有处理都在您的浏览器本地完成，文件不会被上传到任何服务器，确保了隐私和安全。

## ✨ 功能特性

- **纯前端处理**：无需后端服务器，所有操作均在浏览器中完成。
- **扫描效果模拟**：为页面添加灰色背景和微小的随机旋转，模拟真实扫描件的质感。
- **自定义水印**：可以添加自定义的半透明文字水印。
- **可调清晰度**：通过调整渲染缩放比例，平衡输出文件的清晰度和大小。
- **图片化输出**：生成的 PDF 中，每一页都是一张图片，无法选中或编辑其中的文字。

## 🛠️ 技术栈

- **[pdf.js](https://mozilla.github.io/pdf.js/)**：用于解析和渲染原始 PDF 文件的每一页。
- **[jsPDF](https://github.com/parallax/jsPDF)**：用于将处理后的页面（Canvas 图像）合成为新的 PDF 文件。
- **HTML / CSS / JavaScript**：构建工具的用户界面和核心逻辑。

## 🚀 如何使用

1.  直接在浏览器中打开 `index.html` 文件。
2.  点击“选择 PDF 文件”按钮，选择一个本地 PDF 文档。
3.  （可选）在“水印文字”输入框中填写您需要的水印。
4.  （可选）调整“渲染缩放”数值以控制清晰度。
5.  点击“生成扫描风 PDF”按钮。
6.  等待处理完成，浏览器将自动触发新 PDF 文件的下载。
